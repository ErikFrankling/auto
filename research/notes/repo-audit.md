## Assessment

Best direct use: `cazala/automata` for WebGPU/browser experiments because it already exposes multiple CA kernels in WGSL; use it as a browser-side reference/integration candidate, not as the shared Rust/native core. For native+browser parity, custom Rust/wgpu core remains justified. `Ready` is the strongest direct-use desktop explorer for broad model authoring; `Golly`/`lifelib` are best for mature Life-like algorithms and pattern compatibility.

## Evidence limits

The requested 20+ is met, but several named projects (Flow-Lenia, CAPE, Fluoddity) lack a uniquely verified repo identity in this pass. Some records are discovery leads, not audit-grade: their live stars, push date, license, and source paths must be confirmed before a code-reuse decision. Do not treat the approximate dates/counts marked “verify” as verified facts. No repo was cloned or executed. AI-slop calls are reserved for source-backed red flags; README breadth alone is insufficient.
